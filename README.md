# APS4_IA_PI
Nome: Maria Eduarda dos Santos

Implementação do exercício proposto na Prova Intermediária de Robótica 2026.2

Contexto: dado um grid n x n e um agente com movimentos para cima, baixo, esquerda e direita deve encontrar o pacote localizado em qualquer uma das células e carregar até a célula destino, cada movimento custa 1, mas ao passar pelo pedágio, o custo é 3. Há obstáculos pelos quais o agente não pode passar.

ferramentas: biblioteca aigyminsper
Algoritmo: busca em largura

A representação do mundo é feita por números de 0 a 5. Sendo:
0 = obstáculo
1 = agente
2 = célula livre
3 = pedágio
4 = pacote
5 = destino
